# Semáforo JS

Projeto de um semáforo interativo desenvolvido com HTML, CSS e JavaScript puro (Vanilla JS).

## Tecnologias

- HTML5
- CSS3
- JavaScript
- Manipulação do DOM
- `addEventListener()`
- Eventos de clique
- Funções com parâmetros
- Estruturas condicionais
- Arrays
- `setInterval()`
- Propriedade `length`
- `createElement()`
- `appendChild()`
